# FuelTrack — Landing IoT

Segunda versión de la landing de **FuelTrack**, enfocada en el producto IoT para controlar el combustible con precisión. Tiene tres páginas: inicio, el producto y el equipo.

**Stack:** HTML · CSS · JavaScript

## Páginas

- [`index.html`](index.html): qué es FuelTrack, funcionalidades principales, seguridad y escalabilidad, y llamada a la acción
- [`about-product.html`](about-product.html): detalle del producto
- [`about-team.html`](about-team.html): el equipo, su visión y el problema que busca resolver

## Cómo verla

No necesita build: abre `index.html` o sírvela con `npx serve .`
